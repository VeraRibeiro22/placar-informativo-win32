# placar-informativo-win32
O projeto chama-se **"Placar Informativo"** e simula uma plataforma de distribuição de alertas para placares rodoviários. É composto por **três programas Win32** escritos em **C (Win32 API pura)**, todos a correr na mesma máquina, comunicando exclusivamente por mecanismos IPC (sem rede).
